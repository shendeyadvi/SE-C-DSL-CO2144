# Data Structure Lab

This repository contains C programs for my college Data Structure lab practicals.

## Practicals

| File | Topic |
|---|---|
| `practical1.c` | Array operations, searching, and sorting |
| `practical2.c` | Contact management using a linked list |
| `practical3.c` | Bubble sort |
| `parctical4.c` | Browser navigation using stacks |
| `practical5.c` | Queue implementation |

## Compile and run

Compile a practical with a C compiler such as GCC:

```bash
gcc practical1.c -o practical1
```

Run the compiled program:

```bash
./practical1
```

Replace `practical1.c` and `practical1` with the practical you want to run.
