# Data Structures Lab

This repository contains C programs for the Data Structures and Algorithms laboratory course.

## Practicals

| Practical | File | Description |
|---|---|---|
| 1 | [`practical1.c`](practical1.c) | Student marks array operations: insert, delete, display, linear search, bubble sort, and binary search |
| 2 | [`practical2.c`](practical2.c) | Bubble sort for roll numbers, with the array printed after every pass |
| 3 | [`practical3.c`](practical3.c) | Contact management using a singly linked list |
| 4 | [`practical4.c`](practical4.c) | Browser back/forward navigation using two stacks |
| 5 | [`practical5.c`](practical5.c) | Hospital patient queue using a linear array |
| 6 | [`practical6.c`](practical6.c) | Student record management using a binary search tree |
| 7 | [`practical7.c`](practical7.c) | Undirected graph with breadth-first and depth-first traversal |
| 8 | [`practical8.c`](practical8.c) | Library book IDs using a hash table with linear probing |

## Requirements

- A C compiler such as GCC or MinGW
- Windows, Linux, or macOS

## Compile and Run

From the repository directory, compile a program with GCC:

```bash
gcc practical1.c -o practical1
```

Run it on Linux or macOS:

```bash
./practical1
```

Run it on Windows:

```powershell
.\practical1.exe
```

To compile and run another practical, replace `practical1.c` and `practical1` with the required practical number.

Example:

```bash
gcc practical6.c -o practical6
./practical6
```
